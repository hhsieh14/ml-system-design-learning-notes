# Acknowledgments

The primary study reference for this handbook is *Machine Learning System Design Interview* by Ali Aminian and Alex Xu. The book provided the main case-study foundation and many of the design alternatives explored here.

This repository adds an independent study layer: a minimum-scope framework, reorganized comparisons, clarified service boundaries, decision prompts, rewritten explanations, original diagrams, and interview-ready summaries.

The project is unofficial and is not affiliated with the authors, ByteByteGo, or the book's publisher.
